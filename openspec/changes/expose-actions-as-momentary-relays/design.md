# Design

## Context

RelayEntity уже умеет button.press и input_boolean on/off с безопасным echo.
Новые timestamp-домены требуют отдельного импульсного контракта: фактическое
состояние HA не является питанием. Событийный адаптер остаётся самостоятельным.

## Goals / Non-Goals

**Goals:** добавить выбранное пользователем направление через существующий
relay, проверить настоящие HA services и подготовить карточки в Sber.

**Non-Goals:** миграция всех button/script, новый публичный WS API,
гарантированная exactly-once доставка поверх MQTT и отмена HA-сцен.

## Decisions

- RelayEntity распознаёт только input_button/scene как импульсные действия.
- True → press/turn_on; false → пустой список действий. Echo и state всегда off.
- Для этих доменов unknown значит готовность. Удаление состояния даёт unavailable
  через существующий forwarder путь, как у input_boolean relay.
- Для импульсных on_off dispatcher не запускает сравнение устойчивого состояния
  в DevTools: on никогда не будет наблюдаться. Trace сервисного вызова сохраняется.
- Auto остаётся scenario_button: скрытая миграция меняла бы направление уже
  опубликованных устройств. Управление включается явным Relay override.
- Отдельный адаптер-класс и секундный таймер отклонены: хватает узкого расширения
  RelayEntity без задержки и фоновых задач.

## Risks / Trade-offs

- В приложении будет переключатель, а не нативная кнопка → пояснить импульс и
  обратный сброс, проверить пользовательские карточки на живом облаке.
- Sber может сохранить старую карточку после смены категории → проверить
  индивидуальные запросы/модель; не удалять пользовательские связи вслепую.
- Успешный service не доказывает конечные состояния всех устройств сцены →
  не выдавать off за подтверждение результата сцены.

## Migration Plan

Beta1.60.0b3 с файловым откатом. После готовности изменить override только
двух test entities, сохранив Кнопа2/комнату, проверить полный config и off.
Подать диагностическую команду только на test entities и отличать её от
настоящего пользовательского нажатия в Sber. Остальной список сохраняется.

## UI refinement — 2026-11-25

По запросу пользователя развёрнутые пояснения и предупреждение о смене категории
перенесены в значок ⓘ с тултипом в мастере и рядом с выбором категории.
Локализованный текст доступен через title и aria-label; иконка доступна с
клавиатуры, её события не выбирают карточку мастера.
