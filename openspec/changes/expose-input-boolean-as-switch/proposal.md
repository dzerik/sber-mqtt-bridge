# Proposal

## Why

Существующий экспорт `input_boolean` как сценарной кнопки передаёт события из HA в Sber, но не даёт управлять переключателем из Sber. Пользователь одобрил спецификацию управляемого варианта с сохранением текущего поведения и попросил реализовать её.

## What Changes

- Явный выбор `relay` для `input_boolean` в мастере, таблице и YAML.
- Автоматический выбор по-прежнему `scenario_button`, включая старые установки.
- Подтверждение нового управляемого варианта только фактическими состояниями HA, без оптимистической подмены состояния командой.
- Объяснение двух представлений в UI и предупреждение при смене категории.
- Регрессионные проверки команд, ошибок, недоступности, восстановления и сохранения настроек.

## Capabilities

### New Capabilities

- `input-boolean-export`: выбор управляемого или событийного представления логического переключателя HA.

### Modified Capabilities

Нет существующих базовых OpenSpec capabilities.

## Impact

Изменяется карта категорий, обработка command echo для `input_boolean` в `relay`, UI выбора категории, переводы и тесты. Новые зависимости, категории Sber и функции протокола не добавляются. Другие домены не расширяются. Источник — обсуждение пользователя; номер GitHub issue не установлен.
